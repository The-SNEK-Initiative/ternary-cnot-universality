## Summary
We prove that for $k$ ternary wires/qutrits, exactly $k-1$ ternary CNOT gates (forming a spanning tree) are necessary and sufficient to generate the full Lie algebra $so(3^k)$ (classical (quantum-mimetic)) or $su(3^k)$ (quantum), given local $so(3)$ or $su(3)$ generators on each wire.
